一、通用说明

统一响应格式

{
    "code": 0,           // 0=成功, 400=客户端错误, 500=服务端错误
    "message": "success", // 提示信息
    "data": { ... }      // 响应数据（为 null 时不序列化）
}

认证与权限体系

角色Authority说明
普通用户ROLE_USER注册时默认分配，可用所有需要登录的非管理接口
管理员ROLE_ADMIN需数据库直接修改 role 字段，可访问 /api/admin/**

JWT 认证流程

  1. 注册/登录 → 服务端签发 JWT，设置 Redis 缓存（含 ROLE_xxx）
  2. 后续请求在 Header 携带 Authorization: Bearer <token>
  3. JwtAuthenticationFilter 拦截 → 验证 Token → 从 Redis 读取 CachedUser
  4. 将用户 authorities 写入 SecurityContextHolder + UserContext (ThreadLocal)
  5. 管理员接口通过 @PreAuthorize("hasRole('ADMIN')") 保护

用户状态

status含义说明
1正常注册时默认，可正常登录
0禁用管理员操作，登录时报"账号已被禁用"

异常处理

ExceptionHTTPcodemessage
RuntimeException400400异常的 message（动态）
MethodArgumentNotValidException400400第一条校验失败消息
其他 Exception500500"服务器内部错误"
测试建议：先 POST /api/users/register 注册 → 拿到 Token → 放入 Authorization: Bearer <token> → 访问受保护接口。管理员接口需要数据库中将用户 role 字段设为 "ADMIN"，重新登录后生效。

二、用户模块 — /api/users

POST /api/users/register 公开

用户注册。默认分配 USER 角色，status=1（正常）。成功后返回用户信息和 JWT Token。

请求体

字段类型必填校验说明
usernameString是@NotBlank, @Size(min=3, max=50)用户名，3~50位
passwordString是@NotBlank, @Size(min=8)密码，至少8位
emailString是@NotBlank, @Email邮箱
POST /api/users/register
Content-Type: application/json

{
    "username": "john_doe",
    "password": "password123",
    "email": "john@example.com"
}

成功响应 (200)

{
    "code": 0,
    "message": "success",
    "data": { "userId": 1, "username": "john_doe", "token": "eyJhbG..." }
}

错误码

codemessage
400用户名已存在
400邮箱已被注册
400(字段校验失败消息)

请求体

字段类型必填校验说明
usernameString是@NotBlank用户名
passwordString是@NotBlank密码
POST /api/users/login
Content-Type: application/json

{
    "username": "john_doe",
    "password": "password123"
}

成功响应 (200)

{
    "code": 0,
    "message": "success",
    "data": { "userId": 1, "username": "john_doe", "token": "eyJhbG..." }

三、景点模块 — /api/attractions

GET /api/attractions 公开

景点分页列表，支持分类、城市、关键词筛选。仅返回上架（status=1）景点，按创建时间倒序。

Query 参数

参数类型必填默认说明
pageInteger否1页码
sizeInteger否10每页条数
categoryString否-分类筛选
cityString否-城市筛选
keywordString否-模糊搜索（名称+描述）
GET /api/attractions?page=1&size=10&city=北京&category=历史遗迹

成功响应

{
    "code": 0, "message": "success",
    "data": { "records": [ Attraction... ], "total": 100, "page": 1, "size": 10 }
}
GET /api/attractions/{id} 公开

景点详情。访问时自动记录 VIEW 行为并增加浏览计数（登录用户写入 user_behaviors 表）。

路径参数

参数类型
idLong

成功响应

{
    "code": 0, "message": "success",
    "data": {
        "id": 1, "name": "故宫", "category": "历史遗迹", "city": "北京",
        "latitude": 39.9163, "longitude": 116.3972, "rating": 5, "status": 1,
        "viewCount": 1024, "createdAt": "2026-01-01T00:00:00"
    }
}

错误码

codemessage
400景点不存在或已下架

五、推荐模块 — /api/recommendations

GET /api/recommendations 公开

三级递进推荐引擎，登录/未登录均可用。

Query

参数类型默认
limitint10
推荐策略：
未登录 → 全局热门（viewCount 降序）
已登录 Tier 1 → 用户交互过的 Top3 分类同类推荐
已登录 Tier 2 → 用户最常访问的城市同城推荐
已登录 Tier 3 → 全局热门兜底
已登录结果 Redis 缓存 600s。 
GET /api/recommendations?limit=10

成功响应 — List<Attraction>

六、行程模块 — /api/trips

POST/api/trips需认证

创建行程。totalDays 自动计算，status 默认 0。

请求体

字段类型说明
titleString行程标题
descriptionString描述
startDateLocalDate开始日期
endDateLocalDate结束日期
{
    "title": "北京三日游",
    "description": "带家人逛北京",
    "startDate": "2026-07-01",
    "endDate": "2026-07-03"
}
GET/api/trips需认证

当前用户行程列表（分页）。

Query: page (默认1), size (默认10)

GET/api/trips/{id}需认证

行程详情。

codemessage
400行程不存在
GET/api/trips/{id}/attractions需认证

行程景点列表，按 dayNumber + sortOrder 升序。— List<Attraction>

PUT/api/trips/{id}需认证

更新行程。更新日期后自动重算 totalDays。

请求体（全部可选）: title, description, startDate, endDate, status

codemessage
400行程不存在
DELETE/api/trips/{id}需认证

删除行程，级联删除 TripPlanItem。

codemessage
400行程不存在
POST/api/trips/{id}/items需认证

向行程添加景点。

请求体

字段类型说明
attractionIdLong景点ID
dayNumberInteger第几天（默认1）
sortOrderInteger排序号（默认0）
durationInteger游览时长（分钟）
transportModeString交通方式
notesString备注
PUT/api/trips/{id}/items/{itemId}需认证

更新行程景点项（全部可选: dayNumber, sortOrder, duration, transportMode, notes）。

codemessage
400行程景点不存在
DELETE/api/trips/{id}/items/{itemId}需认证

移除行程景点。

codemessage
400行程景点不存在
POST/api/trips/{id}/optimize需认证

智能路线优化，使用百度地图矩阵API + 贪心最近邻算法重排景点顺序。

1. 按 dayNumber 分组 → 2. 百度地图驾车矩阵API 获取距离 → 3. API失败用欧氏距离兜底 → 4. 贪心最近邻重排 → 5. 更新 sortOrder。景点 ≤1 时直接返回。

七、管理后台模块 — /api/admin NEW

所有 /api/admin/** 接口需要 ADMIN 角色。注册默认 USER 角色，需在数据库中将用户 role 字段改为 "ADMIN"，重新登录后生效。
GET /api/admin/dashboard ADMIN

管理后台仪表盘，返回平台核心统计数据。

成功响应

{
    "code": 0,
    "message": "success",
    "data": {
        "userCount": 10,        // 总用户数
        "attractionCount": 25,  // 上架景点数
        "totalBehaviors": 60,   // 总行为记录数
        "todayNewUsers": 1,     // 今日新增用户
        "todayBehaviors": 5     // 今日行为数
    }
}
